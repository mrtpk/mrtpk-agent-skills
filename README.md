# mrtpk-agent-skills

A collection of [Claude Code](https://claude.com/claude-code) skills.

## Skills

- [`skills/codebase-explainer`](skills/codebase-explainer/SKILL.md) — plan and build a static HTML study
  site that teaches an open-source codebase, with cited claims, diagrams, guided tours and a fact-check pass.

## Usage

Clone this repo (or a subfolder) into a project's `.claude/skills/` (or your global skills directory) so
Claude Code can discover and invoke the skills by name.
